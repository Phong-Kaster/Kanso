## Description

Filed by the Verifier (Iteration 11). A fresh-context reader compared README, `docs/features/edit.md`,
`docs/features/tool-screen.md` and ADR-004 with the code (DoD 40's pre-check). Every named path exists and DoD 38's
structure holds, but two sentences are false and three say more than the code. Fix each so it says what the code
does; change no code.

1. **False.** The mermaid block at `docs/features/edit.md:99-100` labels the edge to the renderer
   `filter or intensity changed` and the node `FilterPreviewRenderer: 640 px copy of the original, filter only,
   Dispatchers.Default`. The renderer draws every sticker except the touched one into the copy before the filter
   (`data/edit/edit/FilterPreviewRenderer.kt:62-73`) and also renders when there is no filter but there are
   stickers (`FilterPreviewRenderer.kt:64`, `ToolViewModel.kt:746`). Requests also come from sticker changes
   (`ToolViewModel.kt:401, 459, 468, 476, 511, 530`). The prose at `edit.md:178-182` is already right; make the
   diagram agree with it.
2. **False.** `docs/features/edit.md:447-451` says pictures 69 to 82 "are recorded by
   `screenshots/StickerScreenshotTest.kt`, `DiscardDialogTest.kt` and `EditToolTest.kt`". Only
   `StickerScreenshotTest.kt` records them; the other two capture no image. Split the sentence so the two names
   finish the list of Edit tests they belong to.
3. **Says more than the code.** `docs/features/edit.md:133-134` lists what `EditSettings` holds (crop, shape,
   turns, flips, sliders, filter) and leaves out `stickers`. Add it.
4. **Says more than the code.** README:125, `edit.md:150` and `edit.md:403` say the cropper always shows the photo
   with the stickers drawn. If copying the photo runs out of memory, the cropper shows the photo without stickers
   (`ui/tool/components/EditCropper.kt:220-224`). Say so once where each claim is made.
5. **Says more than the code.** README:137-139 and `edit.md:181-182` list who calls `requestPreview` as if the list
   were complete. It is also called from `changeSettings`, `previewSettings`, `chooseCropRatio`, `undo`, `load`,
   `openTool` and `setComparing`. Either list them all or say "among others".
