## Description

Add section 4 of Home's design below the five tool shortcuts (names fixed in `PLAN.md`):

- "Recent edits": a row with the heading and a round arrow button (`RoundIconButton`, tag `home-recent-more`, icon `ic_arrow_forward`, description a new string) that calls `onSeeAllEdits()`; under it a `LazyRow` `home-recent` of tall rounded cards `home-recent-<i>` (120 dp wide, 160 dp tall, `shapes.large`) for the newest 10 photos, each calling `onRecentClick(uri)` with the content description `R.string.my_edits_photo_description` (T-002 defined it); the thumbnail goes through a slot (`thumbnail: @Composable (Photo, Modifier) -> Unit`, default `PhotoThumbnail`, stand-in boxes in previews: a preview never loads a real Uri). While loading, at least two `home-recent-skeleton-<i>` blocks of the same size (`SkeletonBlock`) and ONE content description on the strip saying photos are loading (no spinner, no `ProgressBarRangeInfo`); when there are none `home-recent-empty` with a short message. KDoc says why placeholders replace a spinner (DoD 37). Previews `HomeEmptyPreview` and `HomeLoadingPreview` (light and dark; still: `ProvideSkeletonPulse(pulsing = false)`) beside the kept `HomePreview`.
- `HomeViewModel(probe, savedPhotos)` reads the source, exposes one `state` and `refresh()`, which keeps showing the photos already loaded while it reads again (no skeleton flash on every return); `HomeScreen` calls `refresh()` each time Home enters the composition (so coming back from Saved shows the new photo first) and wraps its content in `ProvideSkeletonPulse()`.
- Do not change the rows above except as the measurement forces: the DoD 6 budget is cards ending 24 dp above the bar at 360x780 with a 48 dp navigation bar (T-005's rows: carousel 176, five shortcuts 84; yours: gap 12, header 48, gap 4, cards 160). If `HomeReachTest` shows the cards' bottom less than 8 dp above the bar, shrink the carousel (to 160 at the least) and change nothing else; the shortcuts' 48 dp buttons, the bar and the cards' tall shape never change. Never make the shortcut row or the screen scroll to fit.
