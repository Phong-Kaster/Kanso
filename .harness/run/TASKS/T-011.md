## Description

Write the two tests that prove DoD 16 and 18 across the whole app. `AccessibilityWalkTest` walks the merged semantics tree of each enumerated state (Home; gallery full, partial, refused, empty, loading; the editor with each tool selected, unreadable, saving; Saved; camera live, after a shot, refused, unavailable; Settings with Custom selected) and, for every node with a click action, a toggle state or a selected state, asserts a non-empty text or content description and `max(boundsInRoot, touchBoundsInRoot)` at least 48 dp both ways, excluding the nodes under `custom-colour-picker`; it prints the node count per state (each above 0) and fails on a sample 40 dp icon button with no description. `ThemeFollowTest` draws Home, the gallery with photos, the editor with a ready photo, Saved, Settings and the camera (refused, and live with `FakeCameraController`) under `KansoTheme(ThemeMode.Light)` and `(ThemeMode.Dark)` with Kanso blue into bitmaps (`ScreenPixels.kt` pattern; never `captureToImage()`: PROJECT.md Constraint) and asserts a top-bar pixel and a background pixel equal the mode's `surface` (or top-bar container) within ±2 and the luminance bounds of DoD 16.

States that show a `LoadingIndicator` are driven with `mainClock.autoAdvance = false` set before `setContent`.

## Acceptance
