# T-006 - The debug app installs and starts on the emulator

- **Status:** pending
- **Depends on:** T-005
- **Blocked by decision:** -
- **Attempts:** 0 / 3
- **Declared File Scope:** `app/build.gradle.kts`

## Description

Filed by the Verifier (Iteration 8, 2026-10-05). DoD 2's Proof needs the debug build driven once on an emulator, and DoD 19 and 22 are driven on one, but `foreman-device.ps1 -Op install -Apk app/build/outputs/apk/debug/app-debug.apk` fails twice on `emulator-5554` (`sdk_gphone64_x86_64`) with an empty adb reason (`adb: failed to install ...: ` then `foreman-device: failed - the install did not succeed.`, exit 1).

The debug APK is 287 MB on disk, about 348 MB uncompressed: native libraries for all four ABIs (x86 67 MB, x86_64 60 MB, arm64-v8a 44 MB, armeabi-v7a 27 MB; OpenCV, MediaPipe, xeno_native) plus about 40 dex files. Likely cause: the size (emulator storage or the streamed install). First approach: restrict the **debug** build type to the ABIs a person runs it on (`ndk { abiFilters += listOf("x86_64", "arm64-v8a") }` in `buildTypes.debug`), leaving release untouched, with a KDoc-style comment saying why. If the install still fails, the Iteration reads `-Op logcat` / `-Op devices` for a reason before the next attempt; no adb outside the wrapper.

## Acceptance

- `./gradlew :app:assembleDebug` succeeds and the debug APK is clearly smaller (lists only the kept ABIs).
- `foreman-device.ps1 -Op install`, `-Op clear`, `-Op start` exit 0 on the emulator; `-Op logcat` shows no `FATAL EXCEPTION` for `com.phongkaster.kanso`; `-Op dump` contains the six Home tool labels (DoD 2).
- Tests, `verifyRoborazziDebug` and lint stay green; release manifest and dependency checks (DoD 23, 24, R3) unchanged.
