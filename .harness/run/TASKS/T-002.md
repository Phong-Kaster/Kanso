## Description

In `ToneCurve`:
- `init`: at least 2 points, sorted by x, every x and y in 0..1 (drop `first.x == 0f`, `last.x == 1f`).
- `internal fun valueAt(x: Float): Float`: natural cubic spline (zero second derivative at the first and
  last point) through all points; returns the first point's y for x < first.x and the last's for
  x > last.x; result clipped to 0..1. Two points = straight segment.
- `table()` builds its 256 entries from `valueAt` (round(255 × value)); delete Fritsch-Carlson
  `tangents()` and the per-segment clamp.
- `moved(i, x, y)`: the first point's x in `[0, next.x - MIN_GAP]`, the last's in `[prev.x + MIN_GAP, 1]`,
  middle points as today; y clamped 0..1.
- `removed(i)`: any index while size > 2; returns the same curve otherwise.
- `isNeutral`/`NEUTRAL_POINTS` unchanged ((0,0),(1,1)); `added()` keeps MAX_POINTS/MIN_GAP rules and
  must allow x left of the first or right of the last point (it becomes the new end point).
- KDoc updated (:13, :48-51 mention fixed ends and monotone).
