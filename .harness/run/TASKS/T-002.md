## Description

Pure-Kotlin Edit. `Matrix`/`Bitmap` for crop (free, 1:1, 4:3, 3:4, 16:9, 9:16), rotate and flip; `ColorMatrix` for brightness, contrast, saturation, warmth; CPU application of the engine's bundled look-up images (`assets/lookup/*`, `assets/filter_materials/map/*` inside the AARs, reachable as app assets) for at least 6 named filters with an intensity (Q5). Panel: ratio chips, rotate/flip buttons, four sliders, a filter row, 48 dp targets, light and dark previews. The edit applies live to the working copy through the T-001 seam (the panel emits settings; the processor renders). Sliders at their middle give the input pixel for pixel.
