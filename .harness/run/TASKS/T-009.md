## Description

`SavedScreen(tool, photoUri: String, onShare, onEditAnother, onHome)`: shows the saved photo (reuse `PhotoLoader`), three actions. Share builds `Intent.createChooser(ACTION_SEND type image/jpeg, EXTRA_STREAM = the MediaStore content URI, FLAG_GRANT_READ_URI_PERMISSION)` with no package or component named. Edit another pops to `Gallery(tool)`; Home pops to Home (the orchestrator wires the back stack). Back from Saved goes to Home, not to the tool screen. The three actions keep clear of the gesture area (pad by navigation-bar and gesture insets). Pictures `18_saved_light.png`, `19_saved_dark.png`.

Orchestrator wires before dispatch: `Saved` key, `onSaved` from the tool screen, strings.
