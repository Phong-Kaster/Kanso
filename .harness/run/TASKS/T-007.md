## Description

Draw the same grouped choices as rounded cards (PRD item 7, DoD 15): the groups `settings-group-appearance` and `settings-group-colour` are rounded containers (`shapes.extraLarge`) in a `surfaceContainerHigh` or higher role, so the corner pixel differs from the ground by more than 8 in at least one channel (a plain `surfaceContainer` is only about 5 away from `surface` in light mode and could not be told from it); every row (`theme-mode-system`, `-light`, `-dark`; `theme-colour-kanso-blue`; `-wallpaper` only where available; `-custom`) shows an icon inside a tinted rounded square `<row tag>-icon-badge` (a rounded square: width = height within 1 dp; its fill is one scheme container role, e.g. `secondaryContainer`, with the icon in the matching `on...` role; it must differ from the group's colour by more than 8 in at least one channel), then the row's title and a one-line description `<row tag>-description` (non-empty, `maxLines = 1`, different for each row; new strings with the area prefix; every string you add must be used). Keep every existing tag, the radio semantics, the colour swatches and their last-picked-seed behaviour, the picker card and its single `PickerSurfaceColor = Color.White` (PROJECT.md Constraints), the touch targets of at least 48 dp, the large title and the `contentPadding` parameter T-001 added, and the parameter lists of `SettingsScreen` and `SettingsContent`. The wallpaper row stays hidden below Android 12 (`wallpaperColour: Color? = null`). New composables need light and dark previews in the file; keep the preview names `SettingsGroupPreview` and `ColourRowPreview`. `SettingsRowsTest` proves DoD 15's group, badge and description clauses (each Android version its own `@Test`); the existing selection, swatch, picker and restart tests are edited only where the geometry they read moved (never loosen an assertion; tap rows through `TabTaps.tapAboveBar()`).
