## Description

Split `GalleryScreen(viewModel, onBack, onPhotoChosen, modifier, onOpenCamera)` (signature unchanged) into the stateful part (PermissionGate, ViewModel flows, context settings) and a stateless `GalleryContent` taking the tool name, the access (`PermissionAccess`: full, partial, refused, waiting), the albums, the chosen album, the photos and the callbacks. The top bar stays on screen in every access state, as now. `GalleryBody`, `AlbumSwitcher`, `PhotoGrid`, `PhotoCell`, `EmptyGallery` and `PartialAccessNotice` take plain data instead of the ViewModel. Thumbnails load through Coil from MediaStore URIs; in a preview they cannot load, so draw a coloured placeholder (the image's placeholder, inspection mode, or a stand-in parameter) so the grid still looks like a grid. Exact preview names: `GalleryPhotosPreview` (a few albums, a grid of photos), `GalleryPartialAccessPreview` (the notice with its share-more button), `GalleryRefusedPreview`, `GalleryEmptyPreview`.
