## Description

Split the test files below so each holds one top-level type, named after the file. Every move is **word for word** (KDoc, annotations,
the imports the type needs) into a new file in the **same package**. **No test is weakened, renamed or deleted**: every `@Test`
method keeps its name, class name and assertions (the plan compares the test names before and after).

## Rules that bind this task

1. Same package, word for word; do not touch any file outside the scope. The test classes keep their full names (`com.phongkaster.kanso.settings.PickerDefaultAlphaTest` …).
2. **No new top-level type** except the one named after its file (the helper files `PickerMatchers.kt`, `SaveTestSupport.kt`, `ScreenPixels.kt` hold only top-level functions and constants).
3. Every test keeps asserting what it asserts today; a test may only move to a new file.
4. KDoc: keep the existing KDoc on every moved type; add a plain-English KDoc to any moved or new declaration that lacks one.

## Acceptance

1. Each new file declares one top-level type named after it (or only top-level functions/constants for the helper files); each edited file keeps only what the table says.
2. Every `@Test` method name at the base commit still exists; `git diff` shows no assertion line removed that is not added back.
