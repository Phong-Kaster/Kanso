## Description

Face detection with `DetectFaceLandmarkUC(context)` (bundled MediaPipe `face_landmarker.task`) behind `FaceFinder`. Smoothing behind `SkinSmoother`: first choice the engine's beauty shader (`CompositeBeautyProgram`; it needs its own GL thread and an offscreen `extractFrame`, which Retica never used without a surface, so a device spike) and otherwise an OpenCV edge-preserving or bilateral filter limited to the face region from the landmarks. Strength blends smoothed over original in Kotlin (0 = original). Cap at 2000 px. No face -> NoFace failure shown as `retouch-no-face` with the DoD 10 text. Release GL and native resources when the ViewModel clears. Whichever smoother is chosen, name it in the README step list (Retica's Retouch screen was object removal, not skin smoothing; its skin smoothing lived in the Edit screen's Beauty panel).
