## Description

Settings "Theme colour" (default: Wallpaper on API 31+, built-in baseline purple `#6750A4` below, A-002): a Wallpaper option shown only on API 31+ (`dynamicLightColorScheme` / `dynamicDarkColorScheme`) and a Custom option that opens `HSVColorPicker` from `:core:colorpicker`. A seed → full Material 3 `ColorScheme` generator (light and dark), `com.materialkolor` (`DynamicMaterialTheme`/`dynamicColorScheme`, added to the catalog by T-001, A-004), no network at run time. Expose a `SettingsViewModel` function `onCustomColourChosen(Color)` that the picker's `onColorChanged` calls and tests call directly. Put the picker in a node tagged `custom-colour-picker`, on a surface where its text is legible: `HSVColorPicker` hard-codes black text, so in dark mode wrap it in a light `Surface` or similar (do not edit `core/colorpicker`). Applied through `KansoTheme`; the option and seed ARGB persisted in the same DataStore. Unit tests for the generator and the store; Compose tests for immediate application.
