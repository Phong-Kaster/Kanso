## Description

Gestures in `CurveGraph` (contract in PLAN.md "Fixed contracts"):
- tap within 24 dp of a point → select it; else tap within 24 dp of the drawn line (`ToneCurve.valueAt`,
  flat parts included) → add a point at (x, valueAt(x)) via `added()`, select it, one commit; else →
  clear the selection, no commit.
- drag starting on a point → select and drag it (as today); drag starting on the line → add a point
  there, select it and drag it; consume the pointer changes; one commit when the finger lifts.
- remove the long-press branch (:196-204).
- draw the selected point: fill `surfaceContainerLowest`, thicker ring of the line colour.

`CurvesPanel`: `var selected by rememberSaveable(channel)`; remember the last curve handed up; when the
incoming curve differs (Undo, Redo, Reset, channel change) clear the selection. `CurveDeleteButton`
(icon `R.drawable.ic_delete`, written by the Iteration before this task; spoken name new key; tag
constant; ≥ 48 dp; `@PreviewLightDark`) goes in the column's top slot: enabled when a point is selected
and the curve has more than two points; deletes via `removed()` in one `onChange`, then selects the left
neighbour (index − 1) or, deleting index 0, the new index 0.

Tests (`CurvesSheetTest`): DoD 1–7, 10, 12, R6. Rewrite `a_tap_on_empty_space_adds_a_point`,
`a_drag_moves_the_point_and_commits_once`, delete `a_long_press_removes_a_middle_point` (replace with
"long press keeps the point"), re-aim `at_ten_points_a_tap_adds_nothing` at the line with ten unevenly
spaced points leaving a gap wider than 48 dp. `CurveLineContrastTest`: the selected ring ≥ 3 : 1
against the background. `ToolScreenshotTest`: `drawSCurve` drags from the line (press on the line at
x = 0.25 and move down to y = 0.15, then at 0.75 up to 0.85) so the last point stays selected; add
`edit_curves_rgb_overshoot_{light,dark}` (pictures 105, 106: one point dragged from (0.25, 0.25) to
(0.25, 0.75), selected) and `edit_curves_blue_moved_ends_{light,dark}` (107, 108: Blue, first point
dragged to (0.2, 0.1), last to (0.8, 0.9)).
