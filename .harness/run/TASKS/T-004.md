## Description

Phase 4 of the PRD: the live preview with stickers, per PLAN.md's "Live preview" contract.
`FilterPreviewRenderer` draws every sticker except `touchedStickerKey` into the small copy before the filter, and
renders whenever stickers exist even with no filter; the ViewModel's request key adds the stickers minus the
touched one; `touchedStickerKey` is set at gesture start and cleared on the last finger up. `LivePreviewImage`
draws the touched sticker inside the same crop, turn and flip with the slider colour matrix (no filter) and
exposes it through a new semantics property beside `LivePreviewGeometry`. The overlay stops drawing sticker
pictures (frame, buttons and hit areas stay), so nothing is drawn twice. `EditCropper` draws the stickers over
its original image in original coordinates (DoD 20). Compare shows the original with no stickers. Existing
`LivePreviewTest` and `FilterPreviewRendererTest` stay green: with no stickers and no filter the preview stays
null; change them only if a check's premise changed, and say why in the manifest.
