## Description

Filed by the Verifier (Iteration 7). DoD 8 and 13 need fresh, separate full runs of `./gradlew :app:testDebugUnitTest` and `./gradlew :app:verifyRoborazziDebug` to exit 0, allowing one rerun for the known flake. On the finished tree they did not:

| Run | Result |
|---|---|
| `testDebugUnitTest` (fresh) | 198 tests, 1 failed: `ThemeColourSettingsTest.android_15_offers_the_wallpaper_option_and_choosing_it_sets_wallpaper` |
| `verifyRoborazziDebug` (fresh) | 198 tests, 1 failed: `CameraScreenTest.retake_deletes_the_shot_and_shows_the_shutter_again` |
| `testDebugUnitTest` (the one allowed rerun) | 198 tests, 1 failed: `ThemeColourSettingsTest` again |

Both classes pass when run alone, and `--tests '*previews*' --tests '*ThemeColourSettingsTest'` passed twice. So the run's new preview tests do not trigger the failure on their own. It appears only in the full suite.

`ThemeColourSettingsTest` failure (from `app/build/test-results/testDebugUnitTest/`):

```
java.nio.file.AccessDeniedException: ...\robolectric-ThemeColourSettingsTest_android_15_...\com.phongkaster.kanso-dataDir\files\datastore\settings.preferences_pb.tmp -> ...\settings.preferences_pb
	at sun.nio.fs.WindowsFileCopy.move(WindowsFileCopy.java:311)
	at okio.NioSystemFileSystem.atomicMove(NioSystemFileSystem.kt:78)
	at androidx.datastore.core.okio.OkioStorageConnection.writeScope(OkioStorage.kt:140)
	at androidx.datastore.core.DataStoreImpl.writeData(DataStoreImpl.kt:348)
```

On Windows an atomic move fails while another handle has the destination open: a second DataStore or reader on the same file, or the antivirus scanning a fresh file in `%TEMP%`. Find the cause, then make the full suite pass. Allowed: production code in scope, for example a bounded retry of the write or making sure only one store holds the file. Also allowed: test-JVM settings in `app/build.gradle.kts`, for example a per-class fork or a temp dir under `app/build`. **Never** change an existing test (DoD 8). Then check whether the `CameraScreenTest` retake failure still happens.
