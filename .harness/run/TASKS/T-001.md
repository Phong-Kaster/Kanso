## Description

Add `EditTool.CURVES` right after `HSL`. Build the model and formula exactly as PLAN.md "Strategy"
fixes them (CurvePoint, ToneCurve with monotone cubic table, CurveChannel RGB/RED/GREEN/BLUE,
CurveAdjustments rgb/red/green/blue, EditCurves.apply: per-colour table then master table). Add
`EditSettings.curves` and `hasCurveChange`, the `isNeutral(CURVES)` case, the row icon
(`R.drawable.ic_show_chart`) and name, the `EditPanel` case and its `verticalScroll` exemption, and call
`EditCurves.apply` in `EditProcessor.render` after HSL and before the colour matrix. The sheet shows only
the master (RGB) curve in this task (chips come in T-003): `CurvesPanel` (a row with Reset at its end,
the graph below), `CurveGraph` (grid, diagonal guide, curve, points; tap adds, drag moves, long press
removes; one `onPreview` stream and one `onCommit` per gesture; spoken description), `CurveResetButton`.
Every composable in its own file with `@PreviewLightDark` from sample data and KDoc. Fix the tests that
count nine tools or assume HSL is directly before FILTERS. Add pictures 95 and 96 (master curve straight,
light and dark) to `ToolScreenshotTest` — test code only; the Iteration records the baselines. Update
README ("Editing features" row: Curves partial — master curve, no live preview yet; "Curves, end to end")
and the two feature docs.
