## Description

A fresh install, on every Android version, draws every screen in Kanso blue.

1. `KansoTheme` calls `MaterialExpressiveTheme(colorScheme, motionScheme = MotionScheme.expressive(), ...)` (per-use-site `@OptIn(ExperimentalMaterial3ExpressiveApi::class)`), keeping its signature `KansoTheme(themeMode, themeColour = <default>, content)`, `KANSO_THEME_TAG` and `KansoColorSchemeKey` (callers and tests rely on them). It explains the Expressive theme and the spring motion scheme in plain English where first used (CLAUDE.md).
2. `KANSO_BLUE_SEED = 0xFF1A73E8` is one constant in `ui/theme/`. The colour model gains a Kanso blue choice (a data object); the old Baseline purple choice, `baselineColorScheme`, `BASELINE_SEED_ARGB` and the "Default purple" text go (R1). `defaultFor(sdkInt)` returns Kanso blue for every version. Stored names never change: keys `theme_mode`, `theme_colour_source`, `theme_colour_seed`, file `datastore/settings.preferences_pb`. Write the new stored value `"KansoBlue"`; read a stored `"Baseline"`, an unknown value, a `"Custom"` with no seed (Custom's first seed is the blue seed) and a `"Wallpaper"` below Android 12 as Kanso blue; a stored `"Wallpaper"` at Android 12+ stays Wallpaper. Keep `SettingsRepository`'s `sdkInt` constructor parameter, `defaultThemeColour` and `SettingsViewModel.onWallpaperChosen` (other tests call them), and keep `SOURCE_BASELINE` (it parses the old value).
3. Settings' colour rows read, in order, Kanso blue, From wallpaper (Android 12+ only), Custom colour. Keep the existing tags and selection semantics (`Role.RadioButton`, `selectable`): `theme-colour-wallpaper`, `theme-colour-custom`, and a new `theme-colour-kanso-blue` in place of `theme-colour-baseline`. New strings go in `strings_theme.xml` (never rename or move an existing string; the Iteration removes `theme_colour_default`).
4. Expressive typography: no custom typography is needed; screens use the `...Emphasized` styles of `MaterialTheme.typography`. `KansoTheme` hands `MaterialExpressiveTheme` the default expressive shapes and typography.
5. Tests: add `KansoBlueThemeTest` (DoD 1 and the motion-scheme check of DoD 10), `KansoBlueContrastTest` (DoD 17); rewrite the tests that assert the old defaults because the PRD forces it (list in `test-edits.md`). The window-colour check of DoD 1(d) compares `R.color.window_background` with the scheme's background: the Iteration will set the two hex values after reading the failing assertion, so write the assertion, not a guessed hex.
