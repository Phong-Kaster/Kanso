## Description

Add the HSL model and its one per-pixel formula, exactly as PLAN.md "Fixed design" states: `ColourRange`
(nine, centres 0..320 step 40, in the PRD's order: RED, ORANGE, LIGHT_GREEN, GREEN, LIGHT_BLUE, BLUE,
NAVY_BLUE, PURPLE, PINK), `HslChannel` (HUE, SATURATION, LIGHTNESS), `HslAdjustments` (three lists of
nine floats −1..1, `get`, `with` clamping, `isNeutral`, `NEUTRAL`), `EditHsl` (weights, gate, the
apply function over an ARGB `IntArray`, plus small `internal` helpers the tests call: the range weight
for a hue, the gate for a pixel). `EditSettings` gains `hsl` (last constructor parameter) and
`hasHslChange`. Do **not** add `EditTool.HSL` and do not touch `isNeutral(tool)`: that is T-003.
