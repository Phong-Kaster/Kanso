## Description

Found while drafting `evidence/expressive-scan.md` (the analyst's scan of `app/src/main`, read from `material3-android-1.5.0-beta01-sources.jar`). DoD 11's Proof wants every `Button`, `OutlinedButton`, `FilledTonalButton`, `TextButton`, `IconButton`... call in `app/src/main` to pass `shapes =`, or give "no `shapes` overload for that type in material3 1.5.0-beta01" as its reason; a silent gap fails the criterion. Four calls have an overload and do not use it:

1. `ui/permission/AccessRefusedPanel.kt:91` `Button(onClick = onOpenSettings, modifier = buttonModifier)`: a real screen (the "open settings" button of the gallery's and the camera's refused panels). Use the overload `Button(onClick, shapes: ButtonShapes, ...)` (`Button.kt:236` in the sources) with `shapes = ButtonDefaults.shapes()`. **The default padding of that overload (16 dp, `contentPaddingFor(MinHeight)`) differs from the plain one (24 dp, `ButtonDefaults.ContentPadding`); pass `contentPadding = ButtonDefaults.ContentPadding` so pictures 12 to 15 (gallery and camera refused, light and dark) stay as they are.** Keep every existing parameter (modifier, tag) and the text inside.
2. `ui/theme/KansoTheme.kt:262` `Button(onClick = {})` and 3. `:263` `OutlinedButton(onClick = {})`, in `KansoThemePreview`: pass `shapes = ButtonDefaults.shapes()` (overloads at `Button.kt:236`, `Button.kt:713`).
4. `ui/permission/PermissionGate.kt:215` `TextButton(onClick = action.second)`, in the preview helper `SampleGateSlot`: pass `shapes = ButtonDefaults.shapes()` (overload at `Button.kt:864`).

Check each file's imports (`androidx.compose.material3.ButtonDefaults`; `AccessRefusedPanel.kt` may already import it). Do not use any Expressive API that needs an opt-in beyond what the file already has (the `shapes()` overloads of `Button`, `OutlinedButton`, `TextButton` need none; `ButtonDefaults.shapes()` is used the same way in `ui/gallery/GalleryScreen.kt:776` and `ui/tool/ToolScreen.kt:390`: copy that).
