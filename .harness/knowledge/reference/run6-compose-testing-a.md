# Run 6: Compose, Robolectric and screenshot-test facts, Home/camera/transitions notes (part 1)

- Run 6 Phase 1 (2026-10-09, Iteration 2) traps, each cost a review finding or a failed run (evidence: `.harness/run/evidence/p1-full-1.log`, `p1-diff.patch`, `TASKS/T-001.md` to `T-003.md`):
  - Reference: `PreviewCoverageTest` counts a composable as covered only when a preview reaches it through composable-to-composable mentions in the same file, so a non-composable helper between a composable and the composables it calls hides the callee. `HorizontalFloatingToolbar`'s inner Row merges descendants: only clickable or toggleable children stay separate semantics nodes, so a plain `Icon` with a description inside it is not a node. A tap on an icon button also starts a ripple and the pressed-shape morph, so a test of a selection animation must switch the selection without a touch (`viewModel.selectTool(...)` on the UI thread) as well as with one. A `ThemeColourSettingsTest`-style test of colour rows scrolls: `performScrollTo` before a click, `positionInRoot` for order.
  - Reference: Kanso blue's window backgrounds are `#FFF9F9FF` (light) and `#FF111318` (dark), set in both `colors.xml` from the failing assertion of `KansoBlueThemeTest.the_window_background_matches_kanso_blue_in_light_and_dark` (the light/dark `background` of `seedColorScheme(KANSO_BLUE_SEED, dark)`); change the seed and the test names the new values.
  - Reference: a DoD proof that names test classes in `--tests '*XTest*'` is only proved by assertions that live in those classes, so a walk written in another file (the first one lived in `SavedNavigationTest`) must also be in the named class; the review of Phase 1 found two such gaps (DoD 3, DoD 22) and both were closed with tests in `ToolScreenTest` and `ThemeColourRestartTest`.
  - Reference: an `Icon(..., contentDescription = null)` inside a button leaves no node in the merged semantics tree, so a test that wants to know the icon is there tags the `Icon` (`saved-share-icon` and its two siblings) and reads it with `useUnmergedTree = true`. `ButtonGroupMenuState()` has a public constructor in Material3 1.5.0-beta01 and `DropdownMenuItem` draws outside a menu, which is how `ActionMenuItemPreview` shows the overflow item.
  - Reference: with Kanso blue the SDK 35 default is no longer Wallpaper, so a test that needs the wallpaper scheme must choose it (`theme-colour-wallpaper`) and compare against `dynamicLightColorScheme(context).primary` after asserting it differs from Kanso blue's (`ThemeColourRestartTest.wallpaper_choice_survives_a_restart`).
