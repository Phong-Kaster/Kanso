# Kanso is a Material 3 Expressive app, blue by default, with one editor for the five editing tools

While approving Run 3 (2026-10-07), the owner found Kanso's interface "too minimal": plain text rows, no icons
and almost no motion. They asked for some colour, an icon for each feature, transitions, a loading
animation and press effects, all built on the Jetpack Compose animation APIs. On 2026-10-09 they
named the design language: **Material 3 Expressive** (they pointed to the Figma Material 3 Design Kit),
with light and dark mode and a blue primary colour.

The Expressive components (`ButtonGroup`, the floating toolbars, `LoadingIndicator`, `MaterialShapes`,
the wavy progress indicators) ship in Material3 1.5.0. Kanso resolved 1.4.0, which has none of them.
Material3 1.5.0-beta01 declares `minAndroidGradlePluginVersion=9.1.0` and `minCompileSdk=37`. Kanso was
pinned to AGP 8.13, so the work was split into two runs:

- **Run 5** (merged as Phong-Kaster/Kanso#4, `76522d7`) moved the toolchain and nothing a person sees:
  AGP 9.4.1, Gradle 9.6.0, Kotlin 2.4.21, compileSdk 37, Compose BOM 2026.09.00, Navigation 3 1.2.0,
  and Material3 1.5.0-beta01 pinned in the app above the stable BOM. `ExpressiveApiTest` shows that
  the Expressive components can be used.
- **Run 6** (`loop/kanso-m3-expressive-blue`) builds the new look. It stopped part-way, as recorded
  under "Where the work stopped" below.

## What was decided, all by the owner on 2026-10-09

- **The design system is Material 3 Expressive**: `MaterialExpressiveTheme`, the expressive
  `MotionScheme`, and the Expressive component wherever one exists for the job. The owner put it
  directly: Kanso uses Material 3 Expressive and is **not** a copy of Adobe Lightroom.
- **Blue by default.** A new install uses "Kanso blue", generated by MaterialKolor from the seed
  `#1A73E8`. Settings still offers "From wallpaper" (Android 12 and later) and "Custom colour".
- **Light and dark, everywhere.** Every screen follows the app's theme, and the editor follows it too.
- **One editor for the five editing tools**: Edit, Remove background, Enhance, Retouch and Artistic.
  An Expressive toolbar at the bottom switches between them without leaving the screen. Camera
  stays an action on Home, not an editor tool.
- **An icon for every feature**, taken from Material Symbols Rounded and stored as vector drawables.
  They come from `google/material-design-icons` (Apache 2.0), not from an icon library.
- **Motion with meaning**:
  - screen changes use Navigation 3's transitions with the expressive spring, and predictive back;
  - press feedback and shape morphs come from the motion scheme;
  - the system's "Remove animations" setting is respected.

## Considered Options

- **Keep the minimal look of Runs 1-4.** Rejected: the owner found it too bare.
- **Lay the editor out like Adobe Lightroom.** Rejected, and **the closest call**. The Play Store
  screenshots of Lightroom (`com.adobe.lrmobile`) and Snapseed (`com.niksoftware.snapseed`) were
  surveyed, and the owner preferred Lightroom's layout over Snapseed's. A draft PRD then copied
  Lightroom's pattern:
  - a near-black canvas;
  - a two-tier bottom bar whose selection is a blue rounded square;
  - an overlaid slider panel;
  - BEFORE/AFTER chips.

  The owner rejected that draft: they want Material 3 Expressive, not a Lightroom clone. Only the idea
  of one editor with its tools along the bottom survived.
- **Snapseed's playful look** (yellow and green, a film-style strip, pill controls). Rejected: the
  owner preferred Lightroom of the two.
- **An editor that is always dark**, as in Lightroom and Google Photos. Rejected by the owner: the
  editor follows light and dark like every other screen.
- **One screen per tool**, as Runs 1-4 built it. Rejected by the owner in favour of one editor.
- **The beta Compose BOM `2026.10.00`**, the only BOM that maps Material3 1.5.0. Rejected in Run 5's
  D-001: it makes every Compose library 1.13.0-beta01, while pinning Material3 alone keeps it as the
  only pre-release.
